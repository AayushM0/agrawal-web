## What to build

Replace the SMS OTP login flow for community members with instant Email (or Mobile) + Password authentication hardened against OWASP brute-force and credential stuffing attacks.

- In `src/app/login/page.tsx`:
  - Update "Member Login" tab:
    - Input: `Email Address or Mobile Number`
    - Input: `Password` (with eye toggle)
    - Links: `Forgot Password?` (hyperlink to `/forgot-password`) and `Register New Family`
    - Primary CTA: `Log In`
  - Maintain the existing separate `Admin Login` tab completely unchanged.
- In `src/actions/auth.ts`:
  - Implement `loginWithPassword({ identifier, password })`:
    - Enforce rate-limiting lockout via `checkLoginLockout`. Return remaining lockout time if locked.
    - Resolve household or member by email or normalized phone number.
    - Constant-time verification using `verifyPassword`. Perform dummy hash compare on missing account to defeat timing attacks.
