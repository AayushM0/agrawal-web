## What to build

Create the database schema and PostgreSQL data access layer for the Member-to-Member Messaging and Trust & Safety system.

- In `src/db/schema.sql`:

  - Add table `messages` with columns: `id UUID`, `conversation_id UUID`, `sender_id UUID`, `recipient_id UUID`, `message_body TEXT`, `is_flagged BOOLEAN DEFAULT FALSE`, `flag_reason TEXT`, `read_at TIMESTAMP`, `created_at TIMESTAMP`.
