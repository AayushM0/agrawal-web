## What to build

Build a dedicated password recovery flow allowing members to reset forgotten passwords securely via single-use 10-minute email verification codes.

- In `src/app/forgot-password/page.tsx` (New Page):
  - Step 1: Enter registered email ➔ "Send Reset Code".
  - Step 2: Enter 6-digit code received via email + enter & confirm new password ➔ "Update Password & Log In".
  - Clean error states, cooldown timer for resending code, and link back to login.
- In `src/actions/otp.ts` & `src/actions/auth.ts`:
  - Implement `requestPasswordReset(email: string)`:
    - Enforce rate-limiting (max 3 requests per 15 mins).
    - Dispatch branded email via Resend (`verify@maharajaagrasenfoundation.com`) with 6-digit reset OTP.
    - Always return generic success: *"If an account exists with this email, a verification code has been sent"* (OWASP anti-enumeration).
  - Implement `resetPasswordWithOtp({ email, otp, newPassword })`:
    - Verify OTP code against signed HMAC challenge or database token within 10-minute TTL.
    - Validate new password against complexity schema.
    - Hash new password (bcrypt cost 12) and update `households` & `members`.
    - Invalidate reset challenge token so code cannot be reused.
    - Issue fresh `auth_session` cookie to automatically log in the member.

## Acceptance criteria

- [ ] Navigating to `/forgot-password` displays a clean 2-step recovery wizard
- [ ] Requesting a reset sends a 6-digit OTP to the registered email via Resend
- [ ] Non-existent email addresses return identical success response (anti-enumeration)
- [ ] Expired (>10 min) or incorrect OTP codes are rejected
- [ ] Successful reset updates `password_hash` in Supabase, invalidates challenge, and logs in user
